# FSAE 单轮悬架受力计算器

浏览器直接打开 `index.html` 即可使用，或访问 GitHub Pages 网址。

## 这是什么

单文件（无外部依赖）的 FSAE 单轮悬架受力计算器。坐标系为 X 向前 / Y 向左 / Z 向上，单位 mm，原点在整车中心（轴距中点）。默认建模**左前角**，推杆接**上叉臂**。

## 力学模型

- 4 个刚体：上叉臂、下叉臂、立柱、摇臂
- 23 个理想约束：3 个转动铰（叉臂内点、摇臂转轴）+ 2 个球头 + 推杆/转向拉杆二力杆各 1 + 摇臂铰 2 个转动约束
- 未知量 = 23 个约束反力 + 1 个减震器轴向力 = 24；平衡方程 = 4 刚体 × 6 = 24
- 直接解线性方程组 `Jᵀλ = −F_ext`，因此**力臂、转轴方向、各杆方向全部由硬点几何自动导出**，代码中没有写死的力臂或角度
- 摇臂转轴 = 摇臂三点所在平面的法向，硬点改动时自动跟随

## 功能

- 5 个工况同时求解：静态、直线制动、减速入弯（外侧轮）、弯中、加速出弯（外侧轮）
- 输出上/下叉臂全部硬点、推杆、转向拉杆、摇臂枢轴、减震器在各工况下的受力
- 所有硬点坐标、车重、G 值、轮胎与弹簧参数均可编辑，改动后立即重算重绘
- 内置三维视图（鼠标拖拽旋转 / 滚轮缩放 / 右键平移），含硬点受力箭头
- 余量与告警：数值余量（硬点偏移致关键力变化 10% 的位移量）、共面性偏差、摇臂等腰直角偏差、力臂过短、叉臂三角形退化、硬点侵入轮胎/轮辋、轮胎附着利用率等

## 自检

仓库中的力学内核可用 Node 离线校验（需自行从计算器 HTML 抽取脚本）：

```
node ../_verify_susp.js
```

校验项包括力/矩平衡残差、单位垂向力下减震器受压、力臂与虚拟功自洽、±3 mm 随机扰动可解性、退化几何不崩溃等。
